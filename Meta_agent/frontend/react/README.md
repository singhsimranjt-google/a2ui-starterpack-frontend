# {{PROJECT_TITLE}} (React + Vite A2UI Client)

This is a React + Vite + TypeScript frontend application built to render dynamic **Agent-to-User Interface (A2UI)** schemas emitted by Google ADK reasoning agents.

## Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run the Development Server
```bash
npm run dev
```

Open `http://localhost:5173/` in your browser.

### 3. Build for Production
```bash
npm run build
```
The output will be created in the `dist/` folder.
